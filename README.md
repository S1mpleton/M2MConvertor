# M2MConvertor

Учебное приложение комплекса M2M для пошагового преобразования конечных
автоматов Мили и Мура. Варианты загружаются из зашифрованного архива
`BazaVar.m2m`, экспортированного веткой `Codex` приложения M2MTools.

## Первая версия

- выбор BazaVar и номера варианта на начальном экране; направление
  преобразования берётся из варианта;
- последовательная проверка исходного и эквивалентного автоматов в форме
  таблицы, матрицы и графа;
- автоматическое построение эталонного эквивалентного автомата;
- проверка изоморфизма нагруженных ориентированных графов, допускающая
  согласованное переименование состояний, входных и выходных сигналов;
- единый формат сохранения прогресса `*.m2mwork`;
- формирование автономного HTML-отчёта.

При преобразовании Мура → Мили выход состояния назначения переносится на
переход. При преобразовании Мили → Мура состояния разделяются по парам
«состояние назначения, множество выходов». Добавляется начальное состояние
без наблюдаемого выхода: оно сохраняет реакцию исходного автомата с первого
входного сигнала и устраняет неоднозначность, когда в начальное состояние
ведут переходы с разными выходами.

## Сборка и проверка

Требуются CMake 3.19+, C++17, Qt 6.5+ (Core, Widgets, LinguistTools) и
OpenSSL 1.1.1+.

```bash
cmake -S . -B build -G Ninja -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```
